# Clean Code – A Handbook of Agile Software Craftsmanship

## About This Project

I needed a simple summary of *Clean Code: A Handbook of Agile Software Craftsmanship* by Robert C. Martin, so I decided to build this project.

The goal is to summarize the book part by part in clear, practical language that’s easy to read and use online.
