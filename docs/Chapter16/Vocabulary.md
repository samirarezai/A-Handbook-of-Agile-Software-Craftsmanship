## Terms

- **Clover**: A Java code-coverage tool used to measure which lines/branches are executed by tests.
- **Boundary condition**: An edge-case around limits (e.g., end-of-month/year) where off-by-one mistakes commonly appear.
- **Feature envy**: A code smell where a method seems more interested in another type’s data/behavior than its own.
- **Explaining temporary variable**: A refactoring that introduces a well-named variable to clarify an expression/step in an algorithm.
- **Abstract factory**: A pattern for creating related objects without hard-coding concrete types in callers/base classes.
